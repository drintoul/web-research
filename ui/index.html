Web Research Endpoint Tester

A self-hosted web research platform with a unified set of REST and MCP endpoints for search, discovery, scraping, crawling, structured extraction, and browser interaction. This UI lets you exercise every endpoint, manage sessions, and pipe results from one call to the next.
